# Reel Index

A personal streaming directory: pick your services, filter, search, and keep a watchlist.

Live at https://kgw279.github.io/reel-index/

Uses the TMDB API (paste your own free key in setup; it is stored only in your browser). This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming availability by JustWatch via TMDB.

Send to TV: connect Glowhouse in Setup → Send to TV (its address plus a code from the Glowhouse admin page). Each title's page then has a TV picker and a Send to TV button. The Glowhouse sign-in can only list TVs and send titles, stays in this browser, and is never included in a shared setup link.
