Your setup

1. TMDB key

Get a free one at themoviedb.org → Settings → API. Paste either the API Key or the API Read Access Token. It's saved only in this browser.

2. Country

Catalogs differ by country, so pick where you watch.

3. My services

Browse and search only show titles on the services you pick.

4. Share this setup

Makes a link that sets up another phone or browser with your TMDB key, country, services and filters. Each device keeps its own watchlist and can change its own settings afterwards. Anyone with the link can use your TMDB key, so only send it to family.
